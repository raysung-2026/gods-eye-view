# God's Eye View — 繁體中文版 安裝與使用說明

本資料夾內含官方原始碼，加上兩個**本機外掛（不改動上游程式碼）**：

1. `zh-tw/zh-tw-patch.js` — 執行期介面翻譯外掛，會即時把主要介面（頂端工具列、
   資料圖層、場景、顯示設定、監視器、情境總覽、電台、首次啟動導覽、
   POWER UP／服務供應商設定等面板）翻譯成繁體中文。
   只在 `index.html` 加了一行 `<script>` 來載入它，方便未來從官方倉庫
   `git pull` 更新時比對差異。
2. `windows/` — 讓你在 Windows 上「雙擊即可啟動」的安裝與啟動工具。

---

## 需求

- **Windows 10 / 11**
- **Node.js**：官方建議 24.14 以上（或 26.x）。到
  <https://nodejs.org/> 下載 LTS 版本安裝即可；若使用其他新版 Node.js，
  安裝時會看到一個可忽略的版本相容性警告（EBADENGINE），通常仍可正常運作。

---

## 第一次安裝

1. 進入 `windows` 資料夾。
2. 雙擊 **`install.bat`**，會自動下載並安裝所有相依套件（第一次可能要幾分鐘，
   需要網路連線）。
3. 安裝完成後，雙擊 **`create-shortcut.vbs`**，桌面會出現一個
   「**God's Eye View (繁中版)**」捷徑。

## 之後每次使用

- 雙擊桌面上的「**God's Eye View (繁中版)**」捷徑，
  或直接雙擊 `windows\start.vbs`。
- 程式會自動啟動本機伺服器，並用預設瀏覽器開啟
  `http://localhost:4173`。
- 啟動後工作列會有一個縮小的「God's Eye View - 伺服器」視窗，
  **關閉那個視窗就會結束程式**；也可以雙擊
  `windows\stop.bat` 來停止伺服器。

## 選用：加上功能金鑰（API Keys）

不需要任何金鑰就能使用大部分功能（飛機、船艦、地震、CCTV、電台等）。
若想解鎖逼真 3D 地球、語音控制等進階功能，可在程式畫面右下角點擊
「**強化功能**」（原文 POWER UP），依畫面指示貼上金鑰即可，儲存後伺服器
會自動重新啟動。金鑰只會存在你這台電腦上的本機設定檔（`.env`），
不會傳到別的地方。詳情可參考原始 `README.md` 的「API Keys」章節
（此份中文說明沒有重複列出各家金鑰的申請網址，請以英文 README 為準）。

## 更新到官方最新版本

若之後想更新程式碼，可在專案資料夾內執行：

```
git pull
```

由於中文化只多了 `zh-tw/` 資料夾、`windows/` 資料夾，以及
`index.html` 裡新增的一行 `<script>`，一般情況下 `git pull` 不會有衝突；
如果 `index.html` 本身也有上游更新導致衝突，只要保留下方那一行即可：

```html
<script type="module" src="/zh-tw/zh-tw-patch.js"></script>
```

## 疑難排解

- **雙擊捷徑沒有反應 / 瀏覽器沒開啟**：先手動執行
  `windows\install.bat`，看看有沒有錯誤訊息；也可以在工作列找剛剛縮小的
  伺服器視窗，還原看看裡面的記錄訊息。
- **想重新安裝**：把專案資料夾裡的 `node_modules` 整個刪掉，
  再重新雙擊 `windows\install.bat`。
- **翻譯外掛需要調整或新增字詞**：直接編輯
  `zh-tw/zh-tw-patch.js` 裡的 `DICTIONARY`／`LAYER_NAMES` 物件即可，
  不需要重新安裝，重新整理瀏覽器頁面就會套用。
